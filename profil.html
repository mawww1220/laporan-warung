Cadangan & pemulihan data

Lindungi catatan keuangan Anda dari hilang.

Data tersimpan di browser perangkat ini, bukan di internet. Data hilang jika riwayat/data situs browser dihapus atau jika browser dipasang ulang. Data tidak otomatis muncul di HP, komputer lain, atau browser lain. Unduh cadangan secara berkala dan simpan di tempat aman (misalnya Google Drive atau flashdisk).

2. Pulihkan dari file cadangan

Pilih file .json yang sebelumnya diunduh dari aplikasi ini. Sebelum data diubah, Anda akan melihat ringkasan isi file dan diminta memilih: menggabungkan atau mengganti. Kondisi data sekarang otomatis disimpan sehingga impor bisa dibatalkan.

Tentang penyimpanan data

  • Data disimpan di localStorage browser. Ini bukan database server dan tidak tersinkron secara online.
  • Data terikat pada satu browser, di satu perangkat, dan satu alamat. Alamat http://127.0.0.1:5500 dan http://localhost:5500 dianggap dua tempat berbeda. Selalu buka lewat alamat yang sama.
  • Mode penyamaran (Incognito) tidak menyimpan data setelah jendela ditutup.
